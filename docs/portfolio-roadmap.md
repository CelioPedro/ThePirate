# Roadmap de portfolio

Este roadmap organiza os proximos passos para apresentar o The Pirate Max como projeto de portfolio tecnico.

## Fase 1 - Vitrine do repositorio

- Criar README principal com visao de produto, stack, arquitetura e status.
- Separar documentacao de arquitetura e deploy em `docs/`.
- Adicionar links publicos de frontend, API e health check.
- Deixar claro que o projeto esta em MVP tecnico, nao em venda publica final.

## Fase 2 - Evidencia visual

- Capturar screenshots do catalogo.
- Capturar screenshots do login/cadastro.
- Capturar screenshots do carrinho e pedido.
- Capturar screenshots do painel administrativo.
- Adicionar imagens ao README ou a uma pasta `docs/assets/`.

## Fase 3 - Validacao tecnica

- Rodar build do frontend.
- Rodar testes do backend.
- Confirmar health check publico.
- Confirmar endpoint publico de produtos.
- Registrar qualquer limitacao conhecida no README.

## Fase 4 - Publicacao no GitHub

- Confirmar nome final do repositorio.
- Confirmar que nao ha segredos versionados.
- Adicionar descricao curta no GitHub.
- Adicionar topicos como `react`, `spring-boot`, `postgresql`, `docker`, `vercel`, `marketplace`.
- Fixar o repositorio no perfil.

## Fase 5 - Preparacao para venda real

- Configurar Mercado Pago de producao.
- Validar webhook real em dominio definitivo.
- Configurar dominio proprio.
- Rotacionar segredos.
- Revisar termos de uso, suporte e reembolso.
- Melhorar backup e observabilidade.
- Executar compra real de baixo valor em ambiente controlado.
